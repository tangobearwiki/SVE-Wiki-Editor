# SVE Wiki Editor

![Platform](https://img.shields.io/badge/platform-Android-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

星露谷物语扩展（Stardew Valley Expanded）中文百科的安卓离线编辑器。

## 功能

- 一键拉取 SVE Wiki 全站页面到本地
- 离线编辑页面内容
- 语法高亮编辑（WikiText）
- 服务器版本更新检测
- 差异对比（Diff）
- 批量推送修改到服务器
- 命名空间筛选
- 暗色模式
- 自动保存草稿

## 技术栈

- Kotlin + Android
- OkHttp + Gson
- MediaWiki API
- Material 3 Design
