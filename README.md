## 中文

**星露谷物语扩展（Stardew Valley Expanded）中文百科的安卓离线编辑器。**

### 功能

- 一键拉取 SVE Wiki 全站页面到本地
- 离线编辑页面内容
- 服务器版本更新检测
- 差异对比（Diff）
- 批量推送修改到服务器
- 命名空间筛选
- 暗色模式
- 自动保存草稿
- 自动登录

### 技术栈

- Kotlin + Android
- OkHttp + Gson
- MediaWiki API
- Material 3 Design

## English

**An offline Android editor for the Stardew Valley Expanded Chinese Wiki (SVE Wiki).**

### Features

- One-click pull all SVE Wiki pages to local storage
- Offline page editing
- Server version update detection
- Diff comparison (local vs server)
- Batch push modifications to the server
- Namespace filtering
- Dark mode
- Auto-save drafts
- Auto-login

### Tech Stack

- Kotlin + Android
- OkHttp + Gson
- MediaWiki API
- Material 3 Design

## Русский

**Офлайн-редактор для китайской вики Stardew Valley Expanded (SVE Wiki) на Android.**

### Возможности

- Загрузка всех страниц SVE Wiki одним нажатием
- Офлайн-редактирование содержимого страниц
- Обнаружение обновлений на сервере
- Сравнение изменений (Diff)
- Пакетная отправка изменений на сервер
- Фильтрация пространств имён
- Тёмная тема
- Автосохранение черновиков
- Автоматический вход

### Технологии

- OkHttp + Gson
